## ADDED Requirements

### Requirement: Public academic catalog and cohort selection
The system SHALL satisfy the user requirement: "Diferencia claramente entre un programa publicado, una cohorte disponible y una cohorte que admite inscripciones."

#### Scenario: Authorized functional increment
- **WHEN** this increment is implemented using isolated local test data
- **THEN** The third local application consumes actual catalog data, offers search and cohort selection, and preserves selection through authentication.
