# Student dashboard and academic history

## Why
Integrate the UNCSM academic processes using the existing data model and real permissions.

## What Changes
Authenticated student routes show only real own profile, applications, enrolled programs and final academic records, with actionable empty/error states.

## Capabilities
### New Capabilities
- `ecosystem`: Student dashboard and academic history.

## Impact
Local API, backoffice and student portal as applicable. No production mutations or deployments.
