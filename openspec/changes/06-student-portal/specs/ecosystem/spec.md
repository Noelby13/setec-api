## ADDED Requirements

### Requirement: Student dashboard and academic history
The system SHALL satisfy the user requirement: "No inventes asistencia, calificaciones ni porcentajes de avance."

#### Scenario: Authorized functional increment
- **WHEN** this increment is implemented using isolated local test data
- **THEN** Authenticated student routes show only real own profile, applications, enrolled programs and final academic records, with actionable empty/error states.
